# 生存世界生成对照配置

配合 muxi Game Core 1.9.1 使用。本目录没有自动部署操作，正式服务端未修改。

`config/c2me.toml` 基于本机整包现有的公开 C2ME 配置，仅把 `globalExecutorParallelism` 改为 `1`。本地 A/B 使用此文件，在相同坐标顺序下生成两个全新世界，逐方块比较。

原因：原版矿脉也会跨区块写入，C2ME 并行调度可使重叠矿脉的覆盖顺序不同。只统一种子、生成器与维度噪声盐值，不能消除这一类差异。单线程降低新区块生成吞吐量；它不是任意玩家探索顺序下的全世界永久一致保证。

部署本地验证服时，停止该验证服、保存原配置，再把本文件放到其 `config/c2me.toml`，并更新核心 JAR。不要覆盖其他服务器近期调整的配置；也可以只把原配置中的 `globalExecutorParallelism` 设置为 `1`，保留其余选项。

已有区块不会重新生成或被覆盖。独立世界中的玩家修改、随机刻、生物活动及实体 UUID 不属于生成快照一致性的承诺。完整证据与复现命令见 [生成兼容审计](../../docs/dimensions-worldgen-audit.md)。
