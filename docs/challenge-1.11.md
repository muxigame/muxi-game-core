# 僵尸挑战 1.11.1

1.11承接1.10的81×81三层研究所、44房间、零号感染巢穴、特殊敌人和25波极限围攻，新增战术购买、三枪槽、按住补弹及压力节奏。每日任务、登录和昵称功能不改动。

1.11.1将普通挑战僵尸的最终移速由0.12调整为0.21，略低于原版自然僵尸0.23；高速幼尸调整为0.30，仍保持特殊威胁。其他敌人的移速不变。

## 下落与补给

三层破洞 `(8,85,49)` → 二层干草缓冲 `(8,75,49)` → 新打通的北侧连廊 `(8,75,52)` → 二层破洞 `(8,75,54)` → 一层干草缓冲 `(8,65,54)` → 走廊 → 弹药柜 `(40,65,36)`（坐标加对应副本X偏移）。柜旁可站在 `(40,65,39)`。

原生验证包括真实玩家碰撞下落到两个缓冲区，以及缓冲区到下一破洞、最低落点到柜旁的原生寻路。并非只检查方块是否存在。因此保留一层唯一弹药柜，不新增二层柜。

柜体5格内按住TaCZ换弹键，默认R，连续0.5秒。松开、离开距离、打开菜单、失焦或停止发送心跳都会取消；客户端立即清除读条。服务端独立检查持续时长、心跳、房间、生存成员、维度、距离和柜体。完成请求在服务端满足10tick后才补弹，完成后冷却200tick，跨波不重置。右键不补弹，柜外和冷却中仍正常换弹。世界中的标牌由各客户端分别渲染：平时仅“弹药补给点”，冷却时追加该玩家自己的剩余秒数。

三枪弹匣与备弹按实际口径处理；同口径合并，弹药只占槽3及之后，不挤占空主武器槽。常规备弹120–600发；RPG等发射器备弹4–12发，避免把普通枪的120发下限套到火箭。

## 三枪与饥饿

槽0主武器1，槽1主武器2，槽2副武器（仅手枪）。默认免费MP5A5＋空主2＋格洛克17；自带主武器只可选非手枪。三个来源槽不能重复，开局前再次核对完整组件，改装变化须重新选择。

饥饿固定20、饱和度0，并跳过本局自然饥饿/自然回血；不改主世界gamerule。初始肉移除，改为两瓶治疗II，独立占槽3、4。背包、装备、健康、饥饿、位置、模式在离场时恢复。挑战药水效果不带出；进入前原有效果单独保存，离场按经过的游戏时间恢复未过期部分。

## 战斗力价格：不是配方价

携带自选枪及局内新枪均读取服务端已加载的TaCZ枪械数据，估算伤害、弹丸数、射速、弹匣容量、换弹/拉栓时间、类型、穿甲、爆头增益和爆炸范围。自带枪计入真实伤害改装、扩容弹匣及对应换弹脚本参数。默认枪免费；开局前验证每位成员币余额，进入成功后扣费，开局失败会退还已扣携枪费。

估值是玩法预算，不等同真人命中率或实测DPS。短时输出为单发有效伤害×射速；持续输出按整匣伤害/(打空时间＋空仓换弹)计算。RPG额外计估算群体爆炸收益，霰弹枪计多弹丸收益；枪型、穿甲和爆头权重另算。

核心公式：0.30×爆发DPS＋0.55×持续DPS＋0.8×整匣伤害平方根＋0.25×单发威胁，再乘类型/穿甲/爆头系数。局内价格为战斗力×8，按50点向上取整，范围250–16000点；携枪费为战斗力/25向上取整，范围1–80币/枪。该算法完全不读取配方。

局外兑换商店仍按配方材料＋装配费定价，因为它发放永久玩家资产；此逻辑未修改。

## 分类轮盘

默认B键，可在按键设置中修改。分类→子轮盘：手枪、冲锋枪、步枪、机枪、狙击枪、霰弹枪、护甲、爆炸物、补给。选择主1、主2或手枪槽后购买，枪械替换选中槽，最多三把；本局新枪使用原生模型和满首匣，不自动免费灌满备弹。换口径后可去柜旁补弹。

当前候选包括默认枪包中的格洛克、沙鹰、M1911、CZ75、MP5、P90、UMP45、AK47、M4A1、AUG、HK416、SCAR-H、M249、RPK、Kar98k、M700、AWP、M870、M1014、RPG-7；缺失模型自动不展示。护甲支持铁、钻石、下界合金套装。治疗II/跳跃/迅捷药剂分别250/180/180战术点，或2/3/3兑换币。

不暂停战斗。服务端决定价格、槽位、付款类别、存活状态及订单版本；余额不足、重复订单、枪型错槽、背包满均不扣款。本局禁止F换手和Q丢弃绕过三枪槽；局内枪械/护甲/药剂不带出，原始自带枪及组件离场恢复。

## 动态压力节奏

每批10–20只；整波配额均摊，避免尾批只剩几只。基础间隔按10只5秒→20只20秒线性增长。清完立即续批；超时也续批，但不删除旧怪。所有本波配额投放且全部残敌/Boss死亡，才进入下一波。

快速清怪逐步把节奏系数压到0.55，连投也加快；慢批只小幅放缓，上限1.10，而不是不断延长休息。最终间隔约3–22秒；投放每4–7tick最多两只。节奏系数跨波保留，持续制造压力。取消每批聊天通知、固定25秒说明及续批倒数；只保留波次/残敌与Boss状态。波间12秒准备、全员加载后首波30秒保留。

同时存活上限由48提高为96/房间（含Boss及增援）；最多四个房间，总上限384。触及上限时等待清怪，不跳过未投放配额。新增上限不是整合包多人满载性能保证，需上线后观察实际TPS。

## 发布边界

两端使用相同1.11.0 JAR；旧客户端缺少读条、三枪和轮盘，需要同步更新。新地图在创建房间时重建。没有明确批准不重启，有玩家在线只提交和暂存；正式部署前再次备份world/config/旧JAR。1.11待更新包替代先前1.10待更新包，不应混装两个核心JAR。

验证命令：`py build.py --test`、`py tests/run_tasks_smoke.py --challenge`、`py tests/run_tasks_client_smoke.py --tacz`、`py -m unittest discover -s tests -p test_install.py`。客户端测试逐帧断言窗口不可见；测试补丁不进正式JAR。
