# 僵尸入侵挑战（1.8.1）

在常驻任务 HUD 的“挑战任务”分区点击打开大厅，或从任务界面的“挑战任务”页签进入。分区的展开状态保存在客户端。挑战是独立玩法，不消耗每日任务唯一一次刷新，也不改变主线、登录和昵称功能。

## 房间与地图

采用 `muxi_game_core:quarantine` 独立维度，不使用子服。四个房间槽位间隔 256 格，每队最多四人，房主可单独开始。创建房间后生成地图；在线玩家收到房主邀请，五分钟内可接受。房主选择难度并开始，十秒准备倒计时后出怪。等待房间二十分钟自动关闭；已开局不能加入或修改难度。战斗中的房主离线，其余成员仍可继续。

首张地图“封锁研究所”49×49 格，共三层、十二间房；各层中央十字走廊连接四个房间：

| 楼层 | 房间 |
| --- | --- |
| 一层 | 接待大厅、检疫室、安保室、物资仓 |
| 二层 | 实验室 A、实验室 B、医疗站、电源室 |
| 三层 | 指挥室、服务器机房、隔离舱、屋顶防线 |

每层有六处僵尸出生点和悬浮中文房间/设施标识。中央地面设施右键使用：紫珀块上楼、青金石块下楼、金块补充弹药、绿宝石块医疗及食物补给、红石块领取金苹果和箭矢道具。传送有短冷却，尸群会跨层追击。弹药每人冷却三十秒，按难度给予 60/120/180/240 发子弹以及 32/64/96/128 支箭；医疗和道具每人每波各一次。波间刷新额度。地图每个房间每 tick 最多放置 512 个方块；不改主世界。

## 难度和波次

| 难度 | 波数 | 生命倍率 | 攻击倍率 | 奖励倍率 |
| --- | ---: | ---: | ---: | ---: |
| 普通 | 5 | 1 | 1 | 1 |
| 困难 | 10 | 1.5 | 1.3 | 2 |
| 专家 | 15 | 2.1 | 1.7 | 3 |
| 噩梦 | 20 | 2.8 | 2.1 | 4 |

基础生命 20、基础攻击 3，随波次分别递增 7% 和 2.5%。Boss 基础生命 180、攻击 7，也应用难度和波次倍率。人数增加出怪数，不直接增加单怪血量。每队最多 24 只同时存活，总出怪数封顶 48；按间隔逐只刷新。每三波疾行、每四波装甲、每五波 Boss（重叠时 Boss 优先），每波限时五分钟，波间休整十二秒。

Boss 显示独立紫色血条，每八秒有一次带一秒蓄力提示的近身范围攻击。阵亡淘汰并恢复原背包，存活队友继续；主动退出、断线或越出房间也淘汰。全灭或超时失败。当前不支持中途重连继续同一局，也没有倒地复活。服务器维护中的局中断，不补发通关奖励。

挑战僵尸只使用专用追击目标，不保留随机游荡、找村民等原版目标。每秒重新选择本房间最近的存活玩家，每半秒尝试重新寻路，并持续近战攻击。目标跨层、僵尸越界，或远离目标且连续八秒没有移动进展时，回到目标层距离玩家至少八格的合适刷新点继续追击。该机制不保证任意模组地形都可寻路，但避免卡路后无限站桩。

## 装备、保护与恢复

开局需生存模式、关闭容器、放下鼠标上的物品、离开载具。在“携带武器”页从自己的背包选择主、副武器；同一个槽位不能重复选。服务器保存所选物品的完整组件快照，若选择后移动物品或修改配件，开局会要求重新选择。

先把原版背包（含护甲、副手、物品组件、选中栏）、位置、血量、食物和模式写入该玩家存档，再安装临时挑战装备。自选枪械直接复制完整 ItemStack，不按型号重建，因此保留瞄具、枪口、弹匣、附魔和其他组件；原件随原背包保管，离场原样恢复。主、副武器位允许分别选择默认装备，新手不需要自有枪械；默认主武器为格洛克（无 TaCZ 时为铁剑），默认副武器为弓。护甲、盾牌、食物仍由挑战提供。开局和弹药点按实际所选 TaCZ 枪型的弹药配置补给，兼容两把不同口径枪械。

局内锁定物品栏点击及外部容器，使用数字键切换装备；禁止丢出装备、破坏、放置、交互其他实体以及非聊天/挑战指令。怪物不掉物品和经验，不触发每日战斗任务或 Champions 随机词条，避免额外刷取。玩家被击败时拦截正常死亡并离场。退出和断线恢复原背包；异常中断留下的恢复快照在下次登录时恢复。已有饰品仍佩戴，首版不替换模组专属饰品槽。

## 得分与积分商店

普通僵尸击杀 10 分，Boss 击杀 100 分；本人 TaCZ 爆头击杀额外 10 分，以上再乘难度倍率 1/2/3/4。爆头使用服务端枪械击杀事件，并与未取消的真实死亡关联；仅命中头部但没有击杀不加额外分，同一只僵尸不会重复计分。

通关追加（完成波数×100 + 500 + 速度奖励）×难度倍率；速度奖励上限600，三十分钟后为零。击杀分先记账，通关仅追加通关部分，避免重复发分。阵亡、退出和断线保留已获得的击杀积分；积分可跨局保存。局内积分每五秒写盘，正常离场立即保存；异常进程中断可能损失最后五秒尚未写盘的击杀分。

结束后在“积分商店”自主选购物品，不再直接发固定通关物资：

| 商品 | 积分 |
| --- | ---: |
| 绿宝石×4 | 200 |
| 火药×32 | 250 |
| 黄铜×16 | 300 |
| 钻石×2 | 400 |
| 附魔金苹果×1 | 1500 |
| 下界合金碎片×1 | 1800 |
| 格洛克17 | 2500 |
| AK47 | 6000 |

缺少对应模组或枪械模型的商品不显示。客户端只发送商品ID与订单版本，价格和数量由服务器决定；重放相同订单拒绝处理。背包不足则整次购买回滚，不扣分。成功时背包、余额和订单版本在同一玩家存档保存。

另有三个永久一次性挑战任务：

- 首次通关：积分350。
- 累计击杀100：积分600。
- 困难及以上通关：积分1200。

任务为一次性里程碑，领后不会重复发分。旧版已产生的待领物品保留兼容领取入口，不抹除历史奖励。挑战进度、余额、订单版本经过死亡克隆保留。

## 运维与验证

服务端和客户端安装同一个 1.8.1 JAR。独立维度需启动时载入；不能通过普通资源重载上线。仅在线人数为零时允许计划停服部署，先备份核心 JAR 和世界存档，再优雅保存、停服、替换并启动。有在线玩家则只准备待部署文件，不能强制踢人或结束进程。

`deploy-challenge.ps1` 默认仅检查在线人数及构建校验值。带 `-Apply` 时才执行；停止命令本身再次以 `execute unless entity @a run stop` 原子检查无人在线，若未能正常停止则退出，不强杀。离线完整备份世界和配置后调用现有安装器，只启动 Minecraft，不触碰隧道或 FRP。启动后的日志与 RCON 应再次验证。

`py build.py --test` 运行原有规则回归；`py tests/run_tasks_smoke.py --challenge` 验证独立维度、邀请、单人、地图、原背包组件恢复、重连、积分购买去重和背包不足。可加 `--integrations` 带上实际 TaCZ、Champions、Create，验证爆头、改装枪、口径补给。

`py tests/run_tasks_client_smoke.py` 默认以隐藏窗口进行真实客户端离屏渲染。禁用 NeoForge 早期启动窗口，创建 GLFW 窗口时直接设置不可见、不聚焦，并在每帧确认窗口仍不可见；不会弹出游戏界面。它仍使用 OpenGL/显卡，不是无图形驱动的纯协议客户端。隔离服务端完全无GUI、无监听端口。隐藏窗口与禁用监听的 mixin 只打入测试 JAR，绝不进入发布 JAR。

首版数值仍需真实玩家完成整局后调整；自动化用例验证机制，不代表已经完成整包多人实战或经济平衡验收。
