# 僵尸入侵挑战（1.8.0）

在常驻任务 HUD 的“挑战任务”分区点击打开大厅，或从任务界面的“挑战任务”页签进入。分区的展开状态保存在客户端。挑战是独立玩法，不消耗每日任务唯一一次刷新，也不改变主线、登录和昵称功能。

## 房间与地图

采用 `muxi_game_core:quarantine` 独立维度，不使用子服。四个房间槽位间隔 256 格，每队最多四人，房主可单独开始。创建房间后生成地图；在线玩家收到房主邀请，五分钟内可接受。房主选择难度并开始，十秒准备倒计时后出怪。等待房间二十分钟自动关闭；已开局不能加入或修改难度。战斗中的房主离线，其余成员仍可继续。

首张地图“封锁研究所”49×49 格，共三层、十二间房；各层中央十字走廊连接四个房间：

| 楼层 | 房间 |
| --- | --- |
| 一层 | 接待大厅、检疫室、安保室、物资仓 |
| 二层 | 实验室 A、实验室 B、医疗站、电源室 |
| 三层 | 指挥室、服务器机房、隔离舱、屋顶防线 |

每层有六处僵尸出生点和悬浮中文房间/设施标识。中央地面设施右键使用：紫珀块上楼、青金石块下楼、金块补充弹药、绿宝石块医疗及食物补给、红石块领取金苹果和箭矢道具。传送有短冷却，尸群会跨层追击。弹药每人冷却三十秒，按难度给予 60/120/180/240 发子弹以及 32/64/96/128 支箭；医疗和道具每人每波各一次。波间刷新额度。地图每个房间每 tick 最多放置 512 个方块；不改主世界。

## 难度和波次

| 难度 | 波数 | 生命倍率 | 攻击倍率 | 奖励倍率 |
| --- | ---: | ---: | ---: | ---: |
| 普通 | 5 | 1 | 1 | 1 |
| 困难 | 10 | 1.5 | 1.3 | 2 |
| 专家 | 15 | 2.1 | 1.7 | 3 |
| 噩梦 | 20 | 2.8 | 2.1 | 4 |

基础生命 20、基础攻击 3，随波次分别递增 7% 和 2.5%。Boss 基础生命 180、攻击 7，也应用难度和波次倍率。人数增加出怪数，不直接增加单怪血量。每队最多 24 只同时存活，总出怪数封顶 48；按间隔逐只刷新。每三波疾行、每四波装甲、每五波 Boss（重叠时 Boss 优先），每波限时五分钟，波间休整十二秒。

Boss 显示独立紫色血条，每八秒有一次带一秒蓄力提示的近身范围攻击。阵亡淘汰并恢复原背包，存活队友继续；主动退出、断线或越出房间也淘汰。全灭或超时失败。当前不支持中途重连继续同一局，也没有倒地复活。服务器维护中的局中断，不补发通关奖励。

## 装备、保护与恢复

开局需生存模式、关闭容器、放下鼠标上的物品、离开载具。先把原版背包（含护甲、副手、物品组件、选中栏）、位置、血量、食物和模式写入该玩家存档，再替换为临时挑战装备。配发铁甲、盾牌、铁剑、弓箭和食物；装有 TaCZ 且有格洛克模型时配发原生可用格洛克与 9mm 子弹。

局内锁定物品栏点击及外部容器，使用数字键切换装备；禁止丢出装备、破坏、放置、交互其他实体以及非聊天/挑战指令。怪物不掉物品和经验，不触发每日战斗任务或 Champions 随机词条，避免额外刷取。玩家被击败时拦截正常死亡并离场。退出和断线恢复原背包；异常中断留下的恢复快照在下次登录时恢复。已有饰品仍佩戴，首版不替换模组专属饰品槽。

## 得分与奖励

个人得分 =（击杀×10 + 完成波数×100 + 通关加分500 + 剩余速度奖励）×难度奖励倍率。速度奖励上限600，三十分钟后为零。评分 C/B/A/S，由该难度与波数下的个人得分决定。

存活通关获得绿宝石、钻石、火药，以及装有 Create 时的黄铜。数量同时由难度和评分决定。困难起有附魔金苹果；专家起有下界合金碎片。个人击杀达到波数且难度至少困难时，追加枪械：困难格洛克、专家及噩梦 AK47（仅在对应 TaCZ 模型存在时发放）。

另有三个永久一次性挑战任务：

- 首次通关：绿宝石8、钻石2。
- 累计击杀100：火药32、黄铜16。
- 困难及以上通关：附魔金苹果1、下界合金碎片2。

奖励先存入玩家待领队列，离场后在挑战界面领取。背包不足会回滚整次物品插入并保留奖励；领取后队列清空，同次玩家存档包含背包与领取状态，重复请求不会重复发放。队列最多128组，接近满时禁止再开局，避免新奖励丢失。挑战进度经过死亡克隆保留。

## 运维与验证

服务端和客户端安装同一个 1.8.0 JAR。独立维度需启动时载入；不能通过普通资源重载上线。仅在线人数为零时允许计划停服部署，先备份核心 JAR 和世界存档，再优雅保存、停服、替换并启动。有在线玩家则只准备待部署文件，不能强制踢人或结束进程。

`deploy-challenge.ps1` 默认仅检查在线人数及构建校验值。带 `-Apply` 时才执行；停止命令本身再次以 `execute unless entity @a run stop` 原子检查无人在线，若未能正常停止则退出，不强杀。离线完整备份世界和配置后调用现有安装器，只启动 Minecraft，不触碰隧道或 FRP。启动后的日志与 RCON 应再次验证。

`py build.py --test` 运行原有规则回归；`py tests/run_tasks_smoke.py --challenge` 验证独立维度、邀请、单人、地图、原背包组件恢复、重连、奖励去重和背包不足。可加 `--integrations` 带上实际 TaCZ、Champions、Create；`py tests/run_tasks_client_smoke.py` 生成真实客户端截图。隔离服务端不绑定网络端口，相关跳过监听的 mixin 只打入测试 JAR，绝不进入发布 JAR。

首版数值仍需真实玩家完成整局后调整；自动化用例验证机制，不代表已经完成整包多人实战或经济平衡验收。
